## Редакторская проверка

Все 41 исходная статья прошла проверку через Google API, модель google/gemini-3.8-flash: предложено 138 изменений. После ручной сверки выполнено 78 дополнительных уточнений; повторная контрольная проверка выявила ещё два обещания (персонализация и поэтапная оплата), оба исправлены. Проверка не является детектором авторства и не гарантирует рост позиций. Длинные тире в обновляемых текстах и метаданных убраны.

Проверены первичные справочные материалы: [European Panel Federation о МДФ](https://mdf-info.eu/manufacturers/products/mdf), [реакция МДФ на влажность](https://mdf-info.eu/using-mdf/handling-and-storing/controlling-moisture-content), [технические требования Osmo Polyx-Oil Original](https://osmouk.com/product/polyx-oil-original/). Применение Osmo в FAKTURA не заявляется.


## Безопасность обновления

Файл `server/scripts/update-blog-posts-seo-2026-11.sql` обновляет существующие строки одной транзакцией. Сверяет отпечаток проверенных текста и метаданных: чужая правка после аудита вызывает отмену всей транзакции. Повторный запуск не меняет уже обновлённые статьи. updated_at фиксирует реальную дату применения, published_at и created_at не меняются. Изображения и статус публикации не меняются.

В изолированной временной базе проверены: применение всех 41 обновлений с точным чтением результата, сохранение id и дат, повторное применение с нулём изменений и полный откат при конфликте с правкой редактора. PostgreSQL-парсер принял файл; проверены все внутренние адреса статей и товаров. Это не применение на production.


## Как применить на VPS

```bash
sudo git -c safe.directory=/opt/faktura -C /opt/faktura pull &&
sudo docker exec -i supabase-db psql -U postgres -v ON_ERROR_STOP=1 < /opt/faktura/server/scripts/update-blog-posts-seo-2026-11.sql
```

Затем повторить размещение в Timeweb: генерация HTML использует тексты рабочей базы. Если появляется сообщение Article changed since review, не обходить проверку: сначала сверить указанную статью и обновить только нужную редактуру.
