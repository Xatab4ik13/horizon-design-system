## Распределение по страницам (итог)
- `/` — «мебель из массива/натурального дерева на заказ», «изделия из дерева», Москва/СПб
- `/catalog` — «каталог изделий из дерева», «деревянная мебель», «мебель из массива»
- `/catalog?category=doors` — весь кластер «двери из массива»
- `/catalog?category=interior` — кластеры «панно» и «зеркала»
- `/catalog?category=kitchen` — «кухонная утварь, разделочные доски, сервировка»
- `/catalog?category=furniture` — «мебель из сосны/дуба/массива»
- `/catalog?category=crafts` — «подарки, заготовки для творчества»
- `/services` — «мебель на заказ, изготовление, реставрация, деревообработка»
- `/delivery` — «доставка деревянной мебели по России»
- `/blog/*` — информационные запросы (породы, покрытия, уход, выбор)

## Принципы из техкарты
- Один кластер — одна посадочная страница, без пересечений.
- Title: главный запрос кластера + бренд. Description: до 160 знаков с маркерами (на заказ, Москва, доставка).
- H1 один на странице, дублирует главный запрос.
