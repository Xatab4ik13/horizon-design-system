# Редакторская проверка текста услуги

Проверка проведена 20 ноября 2026 через API Google, модель google/gemini-3.8-flash. Использован одноразовый вызов по инструкции AI Gateway for Scripts, без нового сервиса в приложении.

## Результат
- Модель подтвердила соответствие брифу: фрезеровка, дерево/фанера/МДФ, поле 3000 × 2000 мм, адрес в Клину.
- Не обнаружены выдуманные цены, обещания сроков, точности и форматов файлов.
- Коммерческий смысл понятен: услуга, место производства, возможности станка и данные для расчёта.
- Не обнаружены длинные тире и маркетинговые штампы в тексте данных услуги.
- Модель предложила сократить повторения списка материалов и инструкции для расчёта. Сокращены description, блок цены и пояснение о материалах.

## Критическая оценка ответа API
- Замечание о неподтверждённом домене отклонено: faktura-wood.com подтверждён существующим живым сайтом.
- Заголовок, метаописание и микроразметка не выводятся как последовательные абзацы страницы, поэтому повтор ключевых слов в этих полях сам по себе не является переспамом.
- Предложения с длинными тире не применены. Формулировка «тираж деталей» не заменяет необходимые размеры заготовки.
- Адрес сохранён в написании владельца, без догадок о координатах, графике работы и дополнительных помещениях.

Проверка является редакторской оценкой, не детектором авторства. Она не доказывает «написано человеком» и не гарантирует позиции в поиске. Новые обещания должны подтверждаться владельцем.
