# SEO-план по технической карте (FAKTURA)

Цель: рост органического трафика из Яндекс и Google по коммерческим запросам об изделиях из натурального дерева (Москва, МО, Санкт-Петербург). Работаем по техкарте: семантика → техбаза → внутренняя оптимизация → 20–25 статей → нейропоиск.

## Что уже есть (не трогаем)
- SEO-компонент с title/description/canonical/JSON-LD на каждой странице, оверрайды из админки
- Блог на базе данных (5 статей опубликовано), Product/Breadcrumb/FAQ JSON-LD
- robots.txt и статический sitemap.xml

## Этап 1. Семантическое ядро
- Сбор запросов через Semrush по кластерам: мебель из массива на заказ, предметы интерьера и декор, кухонная утварь и сервировка, двери, системы хранения, заготовки для творчества, подарки, эко-мебель без химии, масло-воск, услуги деревообработки
- Комбинация по правилу из техкарты: тип изделия + материал/порода + коммерческий маркер + город
- Группировка и распределение кластеров по страницам (главная, каталог, категории, услуги, статьи)
- Результат: файл семантического ядра + таблица «запрос → страница»

## Этап 2. Техническая база
- sitemap.xml: добавить все статьи блога и товары из базы (предлагаю заменить статический файл на генератор, который сам подтягивает новые статьи и товары — согласовать)
- robots.txt: убрать устаревшую директиву Host (Яндекс её больше не поддерживает)
- Главная: title/description под основной запрос «элементы интерьера и декор, мебель из натурального дерева, деревообработка»
- Проверка: один H1 на страницу, canonical, корректные ответы сервера

## Этап 3. Внутренняя оптимизация страниц
- Уникальные title/description/H1–H3 для всех страниц по семантическому ядру (главная, каталог, каждая категория, услуги, доставка, галерея, блог)
- SEO-тексты на посадочные категорий каталога (короткие, с запросами)
- Атрибуты alt у изображений (товары, галерея, категории)
- Внутренняя перелинковка: статьи → категории/товары, товары → статьи, блок «Полезные статьи»
- FAQ-блоки с краткими ответами + FAQPage JSON-LD на каталоге, услугах, доставке
- Устранение пересечений запросов между страницами

## Этап 4. Контент-план и статьи (20–25)
- Контент-план из 20–25 тем с целевыми запросами — **согласуем список до написания** (требование техкарты)
- Доработка блога: поля seo_title/seo_description, рендер Markdown (H2/H3, списки, таблицы) вместо сплошного текста
- Написание статей пачками по ~5: структура H2/H3, FAQ в конце, ссылки на каталог и товары
- Обложки: существующие фото товаров/галереи
- Черновик тем (уточним на согласовании):
  1. Как выбрать мебель из массива: породы, конструкция, цена
  2. Дуб, ясень, бук, сосна: какая порода подойдёт именно вам
  3. Мебель из дуба на заказ: сроки и стоимость
  4. Масло-воск: почему это лучшее покрытие для дерева
  5. Лак, масло или воск для столешницы: честное сравнение
  6. Мебель на заказ против серийной: что выгоднее
  7. Эко-мебель без химии: как отличить настоящую
  8. Деревянные двери из массива: виды и породы
  9. Системы хранения из дерева: прихожая и гардеробная
  10. Кухня из массива: столешницы, фасады, уход
  11. Деревянная кухонная утварь: выбор и уход
  12. Сервировка деревом: доски и подносы
  13. Заготовки для творчества: породы и виды
  14. Подарки из дерева: идеи на любой повод
  15. Зеркало в деревянной раме под интерьер
  16. Мебель из массива для спальни
  17. Гостиная из дерева: консоли, полки, панно
  18. Влажность и мебель: как избежать трещин и коробления
  19. Дерево в интерьере лофт и сканди
  20. Как проверить качество столярного изделия
  21. Деревянная мебель для ванной: породы и покрытия
  22. Мебель от производителя: 7 преимуществ
  23. Реставрация деревянной мебели: когда нужна
  24. Сроки производства мебели на заказ: из чего складываются
  25. Доставка и монтаж деревянной мебели по Москве и МО

## Этап 5. SEO для нейропоиска
- Краткие фактические ответы на популярные вопросы (FAQ-блоки, выделенные определения)
- Расширение микроразметки: LocalBusiness (адрес, телефон, часы), FAQPage, Article с автором
- Блоки фактов: материалы, сроки, доставка, гарантия — в машиночитаемом виде
- llms.txt с описанием компании и ссылками на ключевые страницы

## Этап 6. Внешние шаги (делаете вы, дам инструкции)
- Яндекс Вебмастер: подтверждение сайта, отправка sitemap, настройка региона
- Google Search Console: то же самое
- Яндекс Бизнес: карточка компании с отзывами

## Важное ограничение
Сайт рендерится в браузере (SPA): Google это читает, Яндекс — плохо и нестабильно. Для серьёзного продвижения в Яндексе сайт можно перевести на серверный рендеринг — обновлением до последнего шаблона Lovable («/» → «Migrate to TanStack Start»), подробности: https://lovable.dev/blog/building-apps-using-tanstack-start. Это отдельная большая задача, обсудим после основных этапов.

## Порядок выполнения
Этапы 1–3 делаем сразу. Затем согласовываем контент-план (Этап 4) и пишем статьи пачками. Этап 5 параллельно со статьями.
